Argonaut network optimization - 2026-11-10

Changes:
- Reuse credential-free HTTP transports across API service instances. Separate
  pools for verified/insecure TLS and REST/streams. Tokens remain per request.
- Enable HTTP/2 with the built-in TLS transport and custom CA trust, retain
  automatic gzip negotiation, and reuse TLS sessions. Idle pools last 5 minutes.
- Remove the hidden 10-second response-header timeout for built-in/custom-CA
  transports; respect call-site request deadlines. Explicit custom transports
  retain their settings.
- All-context overview refresh: 1 minute normally, 2 minutes with low bandwidth.
- Registry cache: memory only, 5 minutes; Ctrl+R bypasses it. Credential or endpoint
  changes invalidate cached data. Apps and registry results arrive independently.
- Fetch only status.resources for the resource tree's Application request.
  Run tree/status reads and describe event/diff reads concurrently.
- --low-bandwidth / [network] low_bandwidth=true replaces Application and tree
  SSE streams with snapshots, limits overview requests to two concurrent calls,
  disables automatic event-panel opening/refresh and release checks, and uses a
  60-second default request timeout unless configured explicitly.
- [network] refresh_interval sets polling; "0" disables periodic snapshots.
  Single-context normal mode retains streams. Manual refresh still works.
- Preserve command/search state, list identity and tree navigation on background
  snapshots. Gate late replies by context/session/sequence and cancel pending
  single-context requests on context changes. Show last-known data on transient
  overview failures, with an explicit error; clear cached data on auth failure.
