2. Developerski git daemon

Domyślny bind: 127.0.0.1. --strict-paths ogranicza eksport do checkoutu
Argonauta i dwóch nazwanych repozytoriów fixtures/history. --export-all
obowiązuje tylko w tej ścisłej liście, nie we wszystkich katalogach obok.
Usunięto fuser zabijający dowolny proces zajmujący port. PID zapisuje daemon.
GIT_DAEMON_LISTEN pozwala jawnie wskazać interfejs osiągalny z k3d; Git nadal
jest protokołem bez uwierzytelnienia, więc dostęp należy ograniczyć do klastra.

Test scripts/git_daemon_test.go pobiera komendę z make -n i uruchamia jej
rzeczywiste argumenty na syntetycznych repozytoriach, wyłącznie na localhost.
Trzy dozwolone repozytoria: dostęp działa. Prywatny sąsiad i zagnieżdżone repo:
odmowa. Nie uruchamiano całego środowiska k3d ani uniksowej otoczki setsid.

3. Przekierowania z tokenem

Zwykły klient i klient SSE stosują ten sam ogranicznik: przekierowanie musi
zachować schemat, hostname i efektywny port. HTTPS -> HTTP, inny port, subdomena
i inny host są blokowane przed wysłaniem żądania do celu. Zachowano callback
niestandardowego klienta i limit 10 przekierowań. Przekierowanie ścieżki w tym
samym origin nadal działa. Nie dodano globalnych timeoutów ani ponawiania mutacji.

4. Pliki manifestów diffu

Wszystkie trzy ścieżki (aplikacja, zasób, rollback) używają prywatnego katalogu
tymczasowego i defer cleanup. Na Unix: katalog 0700, pliki 0600. Obsłużono też
błędy zapisu i startu git. Pliki istnieją do końca synchronicznego viewera.
Viewer musi czekać na zamknięcie widoku, np. code --wait --diff; README to opisuje.
Awaryjne zabicie procesu/systemu omija defer i nadal może pozostawić temp;
poprawka zapewnia sprzątanie przy zwykłym zakończeniu i obsługiwanych błędach.

5. Spóźnione zdarzenia drzewa

Load, stream, błąd i uruchomienie watchera niosą epokę kontekstu oraz numer
sesji drzewa przechwycone przy tworzeniu polecenia. Odbiorca sprawdza oba
numery i aktywny widok przed zmianą stanu. Cleanup unieważnia sesję i wymienia
kanał; goroutine zachowuje wyłącznie kanał swojej sesji. Spóźniony watcher jest
zatrzymywany. Usunięto starą metodę zapisującą do zmiennego kanału modelu.
